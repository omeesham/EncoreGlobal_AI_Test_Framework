# Specs

This is a directory for test plans.

Before authoring a new plan or spec for a module, read **[testcase-authoring-workflow.md](testcase-authoring-workflow.md)** first — it's the step-by-step runbook (planner agent → spec/page-object authoring → xlsx → verification gates → healer agent → cross-instance coverage audit → cross-module standards audit) distilled from building the Local Office Settings suites, and its one rule overrides everything else: always check how an existing module already solved the same problem before writing something new.
