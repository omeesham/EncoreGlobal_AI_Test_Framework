# NM-1559 - Setup > Location, Basic Information tab (parent NM-3489).
# The page while it loads and once loaded, the info tooltip, the left panel
# (Live Date calendar, the Tax Mode, Country, Region and Servicing Branch
# Office lists, the office name refused) and every sub-tab:
# - Local Information: the Billing Cycle, Oracle Organization and Product
#   Organization lists, and a percentage refused with its message;
# - Currency: the merchant lists;
# - Pricing: the currency list, a primary pricing list (and no match), Grid
#   Options (tooltip and menu), a row's effective dates turned on with the
#   date calendar, and the settings panel collapsed;
# - Account and Address: the Account List search (results, a row chosen, the
#   State and Country lists, no match) and both Select Customer Address
#   dialogs (a row chosen, no match);
# - Legal: the service charge and terms lists;
# - Notes: a note added;
# - Shared Setup Locations: the Change Local Office dialog (search results, a
#   row chosen, no match);
# - Auto Add-On and Business Types;
# then the Unsaved changes dialog, the Save Changes confirmation, and the
# message a failed save shows.
# Run: node scripts/generic-testid-audit.js --steps ../NM-1559/config/audit-steps/location/nm-1559-basic-information.txt --office 2359
#
# Changes no data. Every edit stays on screen and is dropped when the page is
# opened again. Dialogs are closed with Cancel or Escape, never Select or Ok,
# and Save Changes is answered Cancel. Only the last Save is answered Ok,
# after the save request is made to fail, so nothing reaches the server.

Module: Location
Submodule: basic-information-nm-1559
Output: reports/testid-audit-location
Elements: all
