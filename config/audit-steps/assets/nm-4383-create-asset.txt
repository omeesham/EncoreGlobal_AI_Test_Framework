# NM-4383 - Asset Search: Create Asset (parent NM-3936).
# The Asset Details sheet, Save with nothing filled (the required-field
# messages), the Current Status and Asset Type lists, each Asset Type (Kit
# Part adds a Kit Asset search box, Kit Asset adds an Assign Kit search box),
# the Select a Product dialog (results, no match, a product chosen), the
# Select a Venue dialog behind Owner Inventory (results, the column menu, the
# next page, a column hidden, a venue chosen) and behind Current Location (no
# match, a venue chosen, the rows-per-page list, 50 rows per page), and
# Save with only the status missing.
# Run: node scripts/generic-testid-audit.js --steps ../NM-4383/config/audit-steps/assets/nm-4383-create-asset.txt --office 2359
#
# Changes no data. Save cannot send anything: Current Status is required and
# its list is empty in this environment, so Save stops at "Status is
# required." The sheet is closed with Cancel. Escape closes the whole sheet,
# so it is used only while a list is open.
