# NM-4990 - Taxes > International Tax Type Setup (NM-4026, parent NM-4019).
# Every state of the page: before a search, the page information tooltip, the
# Country list and the search date's calendar, a refused search date with its
# "Required" marker and tooltip, the filters' tooltips and the filters
# collapsed, Mexico results (as in the ticket screenshot) with the IVA list and
# an empty state's tax type list, the grid while it loads, Canada results, Grid
# Options, each column's menu, a row being edited (GOV and Provincial tax type
# lists, the Effective Date marker and the row calendar), the Unsaved changes
# question, and the message of a failed save.

#
# Changes no data: rows are edited but never saved. The one Save click is made
# while every save request is failed (Fail), so nothing reaches the server.
